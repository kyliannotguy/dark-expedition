# 战锤40K：黑暗远征

中文、单人、回合制浏览器卡牌冒险。首个完整区域为“灰烬巢都”。非官方同人作品，玩法参考 MAOU《卡牌冒险者》与《卡牌冒险者 续》，图案与程序为本次原创实现。

## 立即游玩

**最简单：双击 `黑暗远征.html`。** 这是完整离线单文件，包含全部程序、样式与矢量插图，不需安装依赖或联网。

也可以在本目录打开终端，运行：

```sh
npm start
```

然后访问 **http://localhost:4173**。关闭该终端服务会关闭此地址。端口被占用时可用 `PORT=4174 npm start`，访问对应地址。

`index.html` 是开发入口，也可以直接打开。单文件版本、不同端口和不同浏览器的存档相互独立；建议固定使用一种打开方式。浏览器禁止本地存储时，游戏会显示提示，此时改用本地服务方式。

## 包含内容

- 星际战士、战斗修女、机械教技术神甫三个可选职业，各有十张初始牌。
- 20 种卡牌定义、5 种敌人（包含最终首领）、6 类非战斗事件。
- 12 个普通遭遇：4 场普通/精英战斗和 8 个事件；之后出现最终首领，共 13 个遭遇。
- 双方真实牌组、手牌、资源、坟场、装备与应对规则。
- 战功升级、军需、删牌、军械选牌、购买卡牌、恢复、背包补给与改道。
- 自动存档、继续游戏、教学、行动日志、规则档案、胜利与失败结算。
- 原创矢量人物与武器图案，桌面和手机布局，标准/极速反馈。

## 操作

1. 选择职业并开始远征。第一次建议选择星际战士或战斗修女。
2. 点击桌面的遭遇卡，再选择“进入战斗”或事件行动。
3. 战斗中点击手牌出牌；悬停或用键盘聚焦可以查看详情。未使用的手牌在结束回合后保留。
4. 右键手牌弃置；触屏可点击“弃牌模式”，再点击一张牌。弃牌不会补抽。
5. 应对牌在受击时自动触发，也可提前打出待命。装备点击可卸下到坟场。
6. 每回合开始恢复基础能源并抽牌，临时获得的额外能源不会跨回合保留。
7. 点击医疗包使用；满生命时不消耗。利用医疗站恢复跨战斗保留的伤势。
8. 规则档案随时可查。每次有效行动后自动保存，刷新后点击“继续远征”。

## 已确认与原型假设

完整对照见 `RULES.md`。本作保留已观察到的前期骨架，**不声称精确复刻两作全部规则**。抽牌时点、坟场洗回、装备细节、升级参数、首领流程及部分事件是明确标注的原型设计。

没有联网服务、账号、付费功能、外部美术下载或运行时依赖。尚未加入音效、更多星区和帝国灵能者职业。

## 维护

- `data.js`：职业、卡牌、敌人、事件、冒险序列与原型数值。
- `engine.js`：共享的敌我规则、战斗状态与可序列化存档。
- `art.js`：原创矢量角色和卡牌图案。
- `app.js` / `style.css`：界面和响应式布局。
- `tests/engine.test.js`：规则回归测试与完整远征模拟。
- `build.js`：生成离线单文件，不需要安装任何包。

```sh
npm test
npm run build
```
