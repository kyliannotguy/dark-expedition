# 战锤40K：黑暗远征 · V2 战术重制

中文单人浏览器卡牌冒险，非官方同人作品。玩法灵感来自 MAOU《卡牌冒险者》系列，代码与矢量美术自行制作。

## 启动

推荐在本目录运行 `npm start`，浏览器打开 http://localhost:4173/ 。无需安装依赖。当前已运行的页面刷新即可加载 V2。

便携版：打开 `黑暗远征.html`，不需要网络。浏览器对本地文件存储的支持不同，自动存档建议使用本地服务器版本。

## 本次改进

- 敌人真实抽牌、支付费用、逐张亮牌、触发应对，再逐项显示伤害与状态；默认播放动画，可切换极速。
- 提亮蓝灰终端，敌方暗红、玩家蓝色、装备金色，扩大手牌与正文，窄屏手牌可横向滚动。
- 三个区域：灰烬巢都、铁祸铸造所、殉道者号。33次遭遇、12种敌人、3位区域首领、44张基础牌及攻击牌强化版本。
- 星际战士：标记、连射、锁敌技能；战斗修女：焚烧、虔诚、治疗祈愿；技术神甫：热量、泄压修复、回收与机仆。
- 新增破绽、虚弱、条件伤害、回收、战后选牌、付费强化与每职业两种永久专精。
- 侦察、老兵、炼狱三档；默认老兵。首领具有战术能力，最终首领有第二阶段，久战会增强敌方火力。

## 操作

选择职业和难度 → 选择三张冒险卡之一 → 战斗或事件 → 战后选牌及成长 → 通过三个区域。

点击手牌使用，右键或“弃牌模式”丢弃。未用手牌跨回合保留，每回合通常抽2张，上限10。主动技能按钮会显示冷却或使用条件；应对牌可留在手中自动触发，也可部署待命。装备点击卸下。牌堆、坟场、日志、规则档案随时可查看。

神甫提示：缺血或被标记时可优先泄压；有足够防御时再蓄热用于热能释放。不要只顾输出让热量越过安全阈值。

每次有效行动自动保存。动画播放时刷新会恢复已完成的整段结算。V2使用独立存档，不覆盖旧版；主页“旧版与旧存档”可进入旧局（需同一浏览器及地址）。离线旧版另保存在 `黑暗远征-v1.html`。

## 验证与维护

`npm test`：规则回归与三职业完整通关测试。

`node tests/simulate.js`：三职业 × 三难度 × 20固定种子的180局自动模拟，包含周期性存档恢复。模拟策略有限，结果不是实际玩家胜率。

`npm run build`：重新生成单文件离线版。

配置位于 data.js，共享规则在 engine.js，界面与动画在 app.js，原创图形在 art.js，样式在 style.css。参考证据、原型假设及 V2 新规则见 RULES.md；验证结果见 TESTING.md。

难度与职业强度仍需要真人游玩反馈，尤其炼狱模式。本站未使用官方图片或原作代码，不是 Games Workshop 官方产品。

战斗中右上角“结束并返回”会回到交战前的冒险卡页面，恢复该次交战前的生命、补给与牌组，不消耗遭遇也不获得奖励；重复进入不会重抽开局。旧存档中已经开始的战斗没有战前快照，首次返回会保留当前伤势与补给。左上角标题仍可进入主菜单并保留战斗进度。

## 混合远征与战团扩展 V2.2

开局现在可以选择先锋和独立战区。原有极限战士、战斗修女、技术神甫保留；新增血天使、帝国之拳、火蜥蜴、太空野狼。每个战团都有独立初始牌组、主动技能、被动特性与专精。

敌人不再按战区拆分，而是混入同一条远征牌堆；区域只表示难度递进。当前首领会从符合区域难度的派系首领池中按种子随机出现，例如第一区域可能遭遇混沌星际战士，第二区域可能遭遇死灵领主。

派系来源：

- 黑暗远征：叛军、污染机械与混沌混合火力。
- 腐钟疫区：纳垢恶魔使用疫毒、腐朽恢复与丧钟；解毒牌和净化牌更重要。
- 赤色屠场：恐虐腐化阿斯塔特以自伤换能源、链锯斧与颅骨收割爆发。
- 沉眠墓穴：太空死灵用高斯剥离护盾、活体金属、复苏协议与时滞矩阵。
- 碎颅绿潮：兽人使用多段哒哒哒、WAAAGH、废铁装甲与大砍砍。

远征仍是三张冒险卡选择、十次普通遭遇、区域首领的结构，共33次遭遇；普通敌人与首领都会受种子影响而随机组合。敌人遵守同一套牌堆、手牌、能源、坟场和应对规则；派系差异来自真实卡牌和战术描述。疫毒是新增状态：回合开始损失层数生命并减一层，净化可以清除。
